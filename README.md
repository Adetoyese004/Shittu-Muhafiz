1. Version Control
Version control is a system that tracks and records changes made to files over time. It allows developers to monitor modifications, restore previous versions, and collaborate effectively on software projects.

2. Repository (Repo)
A repository is a storage location for a project's files, source code, and version history. It can be stored locally on a computer or remotely on a platform such as GitHub.

3. Commit
A commit is a saved snapshot of changes made to files in a repository. Each commit has a unique identifier and a message describing the changes.

4. Branch
A branch is a separate line of development in a repository. It allows developers to work on new features or fix errors without affecting the main project.

5. Merge
A merge is the process of combining changes from one branch into another branch. It helps integrate completed work into the main project.
